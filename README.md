# Prática 01 - Desenvolvimento Web

Este repositório contém a entrega da atividade prática solicitada na disciplina de Usabilidade, Desenvolvimento Web, Mobile e Jogos.

## 📝 Sobre o Projeto
O projeto consiste na criação de uma página Web estruturada com **HTML** e estilizada exclusivamente através de um ficheiro **CSS externo**. O conteúdo explora a temática do Cruzeiro Esporte Clube e cumpre a exigência de aplicar cores de fonte distintas para o título principal e para cada um dos três parágrafos.

## 🚀 Tecnologias Utilizadas
* HTML5
* CSS3
